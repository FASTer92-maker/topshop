# Макеты страниц (Wireframes)

> ⚠️ **Требует обновления.** Актуальный визуальный дизайн — дизайн-макет TopShop (PDF: палитра, шрифты, макеты 1440 и 390 px), стиль описан в [PROJECT_SPEC §1.1](PROJECT_SPEC.md#11-визуальный-стиль). Ниже — исходные структурные макеты. В них ещё нет разделов и подкатегорий, выбора размера и цвета, избранного, подписки и строки доставки. Функциональные требования к этим экранам — в [USER_STORIES.md](USER_STORIES.md) (US-03…US-15). Обновление — зона Рамазана, до этапа 8.
>
> Текстовые макеты основных страниц. Ширина макетов соответствует desktop (≥ 1024px), поведение на мобильных описано под каждым макетом.
> Обозначения: `[Кнопка]`, `[____]` — поле ввода, `[▼ ...]` — select, `[x]` — checkbox, `(img)` — изображение, `‹ 1 2 3 ›` — пагинация Pagy.
> Turbo-области отмечены как **⟪turbo-frame: id⟫** и **⟪turbo-stream target: id⟫**.

## 1. Общий layout
`app/views/layouts/application.html.erb`

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 🛍 Top Shop   [ Поиск товаров...              🔍 ]   Каталог  🛒 Корзина (3)│
│                                                         Иван ▾ | Войти  Регистрация│
├──────────────────────────────────────────────────────────────────────────────┤
│ ⟪turbo-stream target: flash⟫                                                  │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ ✓ Товар добавлен в корзину                                           [×] │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│                           <%= yield %>  (контент страницы)                   │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ © 2026 Top Shop · Учебный проект            Каталог · Мои заказы · Контакты  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Шапка** (`layouts/_header.html.erb`):
- Логотип ведёт на `/`.
- Поиск: `form_with url: products_path, method: :get`, поле `q`.
- Корзина: иконка и бейдж с количеством товаров, обёрнутые в `<span id="cart_counter">` ⟪turbo-stream target: cart_counter⟫. Видна только авторизованным.
- Меню пользователя:
  - гость: «Войти», «Регистрация»;
  - customer: «Имя ▾» → «Мои заказы», «Выйти»;
  - admin: то же плюс пункт «Админ-панель».

**Flash** (`layouts/_flash.html.erb`): контейнер `id="flash"`. Notice зелёный, alert красный, есть кнопка закрытия. Turbo Stream может дописывать в него сообщения.

**Мобильная версия:** поиск переносится на вторую строку шапки на всю ширину; меню сворачивается в «☰» (раскрытие на Stimulus-контроллере `toggle` или `<details>`); корзина с бейджем остаётся видна всегда.

- Форма фильтров: `form_with url: request.path, method: :get, data: { turbo_frame: "products", turbo_action: "advance" }`. Скрытые поля переносят `q` и категорию.

## 5. Корзина (`/cart`)
`CartsController#show`. Позиции обрабатывает `CartItemsController` (create, update, destroy).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Корзина                                                                      │
├──────────────────────────────────────────────────────────────────────────────┤
│ ⚠ «Чайник Z» — доступно только 2 шт. Измените количество.   (если есть)      │
├──────┬──────────────────────────┬──────────┬─────────────────┬────────┬──────┤
│      │ Товар                    │ Цена     │ Количество      │ Сумма  │      │
├──────┼──────────────────────────┼──────────┼─────────────────┼────────┼──────┤
│(img) │ Беспроводные наушники    │ 4 990 ₽  │ [−] [ 2 ] [+]   │ 9 980 ₽│ [🗑] │ ← ⟪turbo-stream target: cart_item_12⟫
│(img) │ Футболка базовая         │   990 ₽  │ [−] [ 1 ] [+]   │   990 ₽│ [🗑] │ ← ⟪turbo-stream target: cart_item_15⟫
├──────┴──────────────────────────┴──────────┴─────────────────┴────────┴──────┤
│                                          ⟪turbo-stream target: cart_summary⟫ │
│                                          Товаров: 3                          │
│                                          Итого:  10 970 ₽                    │
│                    [ Продолжить покупки ]   [   Оформить заказ   ]           │
└──────────────────────────────────────────────────────────────────────────────┘
```

- «−» / «+» — это `button_to cart_item_path(item), method: :patch, params: { quantity: n }`. Ответ `update.turbo_stream.erb` заменяет `cart_item_<id>`, `cart_summary`, `cart_counter` и `flash`.
- 🗑 — `button_to … method: :delete`. Ответ `destroy.turbo_stream.erb` удаляет строку и обновляет summary и счётчик. Если позиций не осталось, вся таблица заменяется пустым состоянием.
- «Оформить заказ» неактивна, если `cart.checkout_ready?` ложно.
- Пустое состояние: «🛒 Ваша корзина пуста» и `[Перейти в каталог]`.
- **Мобильная версия:** таблица превращается в карточки: изображение слева, справа название, цена, количество; сумма и удаление снизу. Итог и кнопка закреплены внизу экрана.

## 14. Общие компоненты и состояния

| Компонент | Партиал / хелпер | Описание |
|---|---|---|
| Карточка товара | `products/_product.html.erb` | изображение, название, цена, наличие, кнопка «В корзину» |
| Бейдж статуса | `OrdersHelper#status_badge(order)` | цвет и русское название из `ru.yml` (`activerecord.attributes.order.statuses`) |
| Цена | `number_to_currency(price)` | локаль `ru`: `1 990,00 ₽` (настроить `unit: "₽"`, `format: "%n %u"`, `precision: 0`) |
| Ошибки формы | `shared/_form_errors.html.erb` | список `object.errors.full_messages` |
| Пагинация | хелпер Pagy (`pagy_nav` / аналог в установленной версии) | стили Tailwind |
| Пустое состояние | `shared/_empty_state.html.erb` | иконка, текст, кнопка-действие |
| Хлебные крошки | `shared/_breadcrumbs.html.erb` | |
| Страницы ошибок | `public/404.html`, `public/500.html` | в стиле магазина (этап 18) |

**Цветовая схема (Tailwind):** основной цвет `indigo-600`, успех `green-600`, ошибка `red-600`, фон `gray-50`, карточки `white` с `shadow-sm` и `rounded-xl`.
